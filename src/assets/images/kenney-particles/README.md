# Kenney Particle Pack assets

The PNG textures in this folder are from Kenney's Particle Pack 1.1. They are CC0 and may be used in personal and commercial projects. The original pack's license is included in `LICENSE.txt`.

Source: https://kenney.nl/assets/particle-pack
Pack mirror used for the individual PNG files: https://github.com/Calinou/kenney-particle-pack

`BattleSkillVfx.tsx` colors these textures at runtime and combines them into elemental trails, projectiles, and impact bursts.
